    PIC Pin ──→ LED (+) ──→ LED (-) ──→ 330Ω Resistor ──→ GND

┌────────────┬──────────────────────────────────────────────────────┐
│  PIC Pin   │              Connection                              │
├────────────┼──────────────────────────────────────────────────────┤
│ RC0 (10)   │ ──→ LED1 (Any color) ──→ 330Ω ──→ GND              │
├────────────┼──────────────────────────────────────────────────────┤
│ RC1 (9)    │ ──→ LED2 (Any color) ──→ 330Ω ──→ GND              │
├────────────┼──────────────────────────────────────────────────────┤
│ RC2 (8)    │ ──→ LED3 (Any color) ──→ 330Ω ──→ GND              │
├────────────┼──────────────────────────────────────────────────────┤
│ RC3 (7)    │ ──→ LED4 (Any color) ──→ 330Ω ──→ GND              │
├────────────┼──────────────────────────────────────────────────────┤
│ RC4 (6)    │ ──→ LED5 (Any color) ──→ 330Ω ──→ GND              │
└────────────┴──────────────────────────────────────────────────────┘

LED Polarity:
    + (Anode)  = Long leg  → Connect to PIC pin
    - (Cathode) = Short leg → Connect to Resistor → GND

╔═══════════════════════════════════════════════════════════════════════════╗
║                    Quick Troubleshooting Guide                            ║
╚═══════════════════════════════════════════════════════════════════════════╝

Problem: PICkit 3 not detected
├─ Check USB cable
├─ Check PICkit 3 LED (should be green)
└─ Reinstall MPLAB IPE

Problem: Target not detected
├─ Check all 5 wire connections
├─ Verify VDD = 5V (use multimeter)
└─ Check VSS = GND

Problem: Programming failed
├─ Try slower programming speed
├─ Erase chip first
└─ Check for short circuits

Problem: LEDs not blinking after programming
├─ Disconnect PICkit 3
├─ Use separate 5V power supply
├─ Check LED polarity (+/- correct?)
└─ Verify 330Ω resistors are present


╔═══════════════════════════════════════════════════════════════════════════╗
║                          Safety Warnings                                  ║
╚═══════════════════════════════════════════════════════════════════════════╝

⚠️  Use exactly 5V - Higher voltage will damage the chip!
⚠️  Always use resistors with LEDs - Direct connection will burn LED!
⚠️  Check polarity before connecting - Wrong polarity = damage!
⚠️  Don't hotplug while programming - Power off first!
⚠️  Use proper wire gauge - Too thin = unreliable connection!
